Rule 1

TO BE (am / is / are)

Use TO BE when there is NO action verb. Use it for names, ages, feelings, jobs, places, and adjectives.

  • • I am / am not (Am I...?)
  • • He / She / It is / isn't (Is she...?)
  • • You / We / They are / aren't (Are you...?)
Rule 2

Action Verbs (go, live, like...)

Use DO / DOES / -s when there IS an action verb (go, like, live, work, play, have, eat, sleep).

  • • I / You / We / They: verb / don't + verb / Do ... verb?
  • • He / She / It: verb-s / doesn't + verb / Does ... verb?
